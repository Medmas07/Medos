# API Contracts

Place validated, versioned cross-component API specifications here, one directory per capability or providing component. A contract may exist before the component that provides it is decided; the table says so. File names carry the major version (`<name>.v<major>.yaml`); a breaking change creates a new file instead of editing the old one.

Every contract is checked by the repository [contract tests](../../tests/contracts/): it must be valid OpenAPI, and each embedded example must match its schema. Authentication convention ([ADR-0010](../../docs/decisions/ADR-0010-authentication-foundation.md)): an operation that accepts a person's session declares the `bearerSession` HTTP bearer scheme of [`authentication.v1.yaml`](auth/authentication.v1.yaml), as optional (`{}` first) while its provider can run with authentication off. Since HC-212 ([ADR-0011](../../docs/decisions/ADR-0011-role-based-access-control.md)), such an operation also answers `403 permission_denied` when the person's role does not grant it. Service-to-service authentication is OPEN.
