# Cross-System Tests

- [`contracts/`](contracts/): IMPLEMENTED. Checks every contract under [`contracts/api/`](../contracts/api/README.md) and [`contracts/federation/`](../contracts/federation/README.md): each must be valid OpenAPI, and each embedded example must match its schema. It also tests boundary rules. Federation: shared schemas stay identical, examples use canonical demo ids, entries come only from nodes that answered, and a result is complete only if every node answered. Medication safety: an LLM cannot be the safety source, results stay pending clinician review, and outcome and warnings agree. SciAgents: result and error follow status, results are research-only, requests cannot carry clinical or identifying data, and example references resolve. Run it from `tests/contracts/` with `python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt && pytest`. CI runs it when contracts change.
- `integration/` and `e2e/`: PLANNED, empty placeholders for cross-service integration, Federation, deployment, and end-to-end journey tests.
