# Architecture Decision Records

Copy [the template](template.md) to `ADR-NNNN-short-title.md`. Keep records immutable after acceptance; add a superseding ADR when a decision changes.

Use an ADR for consequential choices including backend and frontend frameworks, database, ORM, NestJS, FastAPI, a combined NestJS/FastAPI topology, Docker, authentication, REST/GraphQL, WebSocket, deployment, AI integration, and monolith/services boundaries.

Clean/Hexagonal principles are an initial project constraint and do not require a new decision record.
