# Agent Startup Checklist

Before coding or claiming implementation status:

1. Read [AGENTS.md](../AGENTS.md).
2. Read the [canonical product vision](product/FEDERATED_HEALTHCARE_ECOSYSTEM.md).
3. Read the [technical architecture](architecture.md).
4. Read [CURRENT_STATUS.md](CURRENT_STATUS.md).
5. Read the current ticket and its acceptance criteria.
6. Read the relevant component README.
7. Read relevant [ADRs](decisions/README.md).
8. Inspect the actual code and repository state.
9. Confirm whether dependencies and behavior are PLANNED, MOCKED, IMPLEMENTED, or VALIDATED.
10. Do not infer missing behavior, technology, security, or validation.

If sources conflict, use the hierarchy in [the documentation index](README.md#source-hierarchy) and surface unresolved contradictions.
